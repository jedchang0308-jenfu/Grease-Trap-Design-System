# ADR-002｜雙軌任一有效軌即可產生報告草稿

狀態：Accepted；報告出口由 ADR-009 更新

日期：2026-07-13；2026-07-17 updated

## Decision

雙軌案件只要一軌資料足夠且計算成功，即可預覽與匯出報告草稿；另一軌以非阻擋提醒明示。系統不得靜默降級，也不得建立假結果。

| 有效軌數 | 狀態                     | 報告草稿                   |
| -------: | ------------------------ | -------------------------- |
|        2 | `COMPLETE`               | 可預覽與匯出               |
|        1 | `COMPLETE_WITH_REMINDER` | 可預覽與匯出，並揭露不足軌 |
|        0 | `BLOCKED`                | 不可預覽或匯出             |

每一要求軌都保存 `TrackAssessment`；只有有效軌保存 `CalculationRun`。此放行只代表可形成計算草稿，不代表正式簽核、法規核准、產品符合性或後端可信度。
