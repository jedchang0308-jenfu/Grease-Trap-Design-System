# ADR-001｜現行 Q/G 與舊版 Q/V 採雙軌一級功能

狀態：Accepted  
日期：2026-07-13  
決策來源：HD-01、HD-02、HD-05

## Context

客戶案件的已知資料與要求不同。現行方法以 Q/G 表達設計需求，實務上仍有客戶要求舊版 Q/V 公升容量換算。只保留任一方法都不能完整服務既有需求；混成單一公式則會破壞法規時效與單位語意。

## Options

- A：只做現行 Q/G。
- B：只做舊版 Q/V。
- C：新舊雙軌都是一級功能，共用案件治理但隔離計算。
- D：現行先做，舊版延後或人工附件處理。

## Decision

採 C。

## Chosen rule

- 模式固定為 `CURRENT_QG`、`LEGACY_QV`、`DUAL_COMPARISON`。
- 新案件預設 `CURRENT_QG`，工程人員可明確選其他模式。
- 兩軌使用不同 calculator、參數命名空間、單位、run、結果語意與報告章節。
- 五個任務在兩軌都必須獨立可用。
- 不建立第三套混合公式，不自動取兩軌較大值，不因缺資料靜默降級。
- 舊版報告必須標示「歷史指引方法」，不得包裝成現行 Q/G 設計結論。

## Consequences

- 需要兩套版本化參數與回歸測試。
- 資料模型必須區分 L/min、L/h、Veff、Q 設計能力與 G 設計能力。
- 報告與 UI 增加雙軌分欄，但能消除人工重算與語意混用。

## Compatibility

本 ADR 延續並取代專案外 v0.1～v0.4 中散落的雙軌描述。本專案的 SPEC-001 是工程權威來源；任何程式或後續規格若與本 ADR 衝突，必須建立明確後繼 ADR。
