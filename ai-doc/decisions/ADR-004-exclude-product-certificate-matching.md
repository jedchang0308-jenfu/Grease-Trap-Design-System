# ADR-004｜第一版排除產品與證書匹配

狀態：Accepted  
日期：2026-07-13  
決策來源：HCS-1A 與使用者補充「證書匹配功能拿掉不需要」

## Context

系統核心價值是把內政部給排水規範（附錄 5）與臺北市工務局衛工處設計說明的設計依據、換算過程與報告標準化。產品型號、額定能力與證書有效性屬於另一套主資料與符合性判定，會增加資料維護、責任語意與驗證成本。

## Options

- A：計算成立即可核發設計需求計算書，產品匹配不影響放行。
- B：缺產品匹配只能產生草稿。
- C：缺產品匹配不影響計算依據的數學結果；產品匹配屬於本系統範圍外。

## Decision

採 A，並進一步將產品型號與證書匹配功能從第一版完整移除。

## Chosen rule

- 內政部給排水規範（附錄 5）只輸出設計需求 Q/G 與反推的等效上限。
- 系統不保存產品型號、額定 Q/G、證書或匹配狀態主檔。
- 正式計算書可以在計算成立且覆核完成後核發。
- 報告必須在限制章節說明：本報告未執行特定產品或證書符合性判定。
- 未來若要加入選型或證書功能，必須由新的人類決策、ADR、獨立 DEV 與驗證計畫重新進入，不得從本次文件推定已授權。

## Consequences

- 移除產品模組、產品 API、產品 UI、資料表與匹配測試。
- 原 DEV-006 標記為跳過，保留 ID 與決策來源。
- 現行反推改由使用者輸入 Q/G 設計能力與證據來源，不宣稱證書真偽已驗證。

## Compatibility impact

這是對 SPEC-001 v1.0、SPEC-002 v1.0、QA-001 v1.0、DEV-006 與 ADR-002 產品匹配敘述的 Intentional replacement。
